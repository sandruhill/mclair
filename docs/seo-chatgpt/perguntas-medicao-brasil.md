# Perguntas para medir presença no ChatGPT (Brasil)

Como usar: uma vez por semana, abrir o ChatGPT em janela anônima (sem login ou com conta limpa, busca ativada), localização São Paulo, e colar cada pergunta como está. Anotar em planilha: (1) o site foi citado? (2) a marca aparece no texto mesmo sem link? (3) quais concorrentes e quais fontes aparecem. As fontes que aparecem para os concorrentes viram novos itens da lista de citações.

A coluna "Página que deveria responder" usa só URLs que estão no sitemap hoje (todas com barra final, que é a URL canônica).
